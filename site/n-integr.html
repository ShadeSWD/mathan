Глава 3. Численное интегрирование

Интеграл в инженерной задаче почти никогда не берётся аналитически: подынтегральная функция задана таблицей ординат или считается программой. Численное интегрирование устроено просто — функцию заменяют интерполяционным полиномом и интегрируют его. Вся тонкость в том, чтобы знать порядок получающейся ошибки и уметь её оценить, не зная точного ответа.

Аналитическая пара главы — «Интеграл» (определённый интеграл). Там интеграл берётся точно по формуле Ньютона — Лейбница, когда первообразная существует в элементарных функциях; здесь — приближённо по ординатам, когда её нет или функция задана таблицей.

3.1. Идея квадратурных формул

Любая формула численного интегрирования имеет вид

$$\int_a^b f(x)\,dx \approx \sum_{i=0}^{n} A_i\,f(x_i),$$

где \(x_i\) — узлы, \(A_i\) — веса. Формулу называют точной для полиномов степени m, если она даёт точный результат для любого такого полинома; величину m называют алгебраической степенью точности. Если узлы заданы заранее и равномерны, получаются формулы Ньютона — Котеса; если узлы тоже подбирают, степень точности удваивается — это квадратуры Гаусса.

3.2. Три базовые формулы

Прямоугольники заменяют функцию константой, трапеция — прямой, Симпсон — параболой. Каждое повышение степени добавляет два порядка точности составной формулы.

средних прямоугольников\(h\,f\!\left(\tfrac{a+b}{2}\right)\)1 \(\tfrac{h^3}{24}f''(\xi)\)

Обратите внимание на строку Симпсона: формула построена по параболе, то есть точна для полиномов второй степени по построению, — но оказывается точна и для кубических. Причина в симметрии: кубическая добавка даёт по обе стороны от середины равные по модулю и противоположные по знаку вклады, которые взаимно уничтожаются. Этот «бесплатный» порядок и сделал формулу Симпсона стандартом.

3.3. Составные формулы

Отрезок делят на n равных частей длиной \(h = (b-a)/n\) и применяют формулу к каждой части. Для трапеций и Симпсона (n чётно):

$$I_{\text{тр}} = h\left(\dfrac{y_0 + y_n}{2} + \sum_{i=1}^{n-1} y_i\right), \qquad R_{\text{тр}} = -\dfrac{(b-a)h^2}{12}\,f''(\xi),$$

$$I_{\text{С}} = \dfrac{h}{3}\Bigl(y_0 + y_n + 4\!\!\sum_{i\ \text{нечёт}}\!\! y_i + 2\!\!\sum_{i\ \text{чёт}}\!\! y_i\Bigr), \qquad R_{\text{С}} = -\dfrac{(b-a)h^4}{180}\,f^{(4)}(\xi).$$

Порядок точности \(O(h^2)\) против \(O(h^4)\): уменьшение шага вдвое снижает ошибку трапеций вчетверо, а Симпсона — в шестнадцать раз. Отсюда практическое правило: при гладкой функции всегда предпочитайте Симпсона, он не дороже по числу вычислений.

Числовой пример. \(\int_0^1 e^{-x^2}dx\) (точное значение 0,746824) при n = 4, h = 0,25. Ординаты: 1,000000; 0,939413; 0,778801; 0,569783; 0,367879.
\(I_{\text{тр}} = h\left(\frac{y_0+y_4}{2} + y_1+y_2+y_3\right)\) = 0,25·(0,683940 + 2,287997) = 0,742984
ошибка трапеций = 0,746824 − 0,742984 = 3,84·10⁻³
\(I_{\text{С}} = \frac{h}{3}\bigl(y_0+y_4+4(y_1+y_3)+2y_2\bigr)\) = (0,25/3)·(1,367879 + 6,036784 + 1,557602) = 0,746855
ошибка Симпсона = 0,746824 − 0,746855 = −3,1·10⁻⁵
При одном и том же числе ординат Симпсон точнее в 124 раза — ровно тот порядок, который обещает теория.

3.4. Правило Рунге и уточнение по Ричардсону

Оценить ошибку, не зная точного ответа, позволяет сравнение двух счётов с разными шагами. Если метод имеет порядок p, то \(I - I_h \approx C h^p\), и для шагов h и h/2

$$I - I_{h/2} \approx \dfrac{I_{h/2} - I_h}{2^p - 1}$$

— это правило Рунге. Прибавив оценку к \(I_{h/2}\), получаем уточнённое значение (экстраполяция Ричардсона):

$$I \approx I_{h/2} + \dfrac{I_{h/2} - I_h}{2^p - 1}.$$

Для трапеций \(p = 2\) и поправка равна трети разности; примечательно, что результат совпадает с формулой Симпсона на той же сетке. Последовательное применение экстраполяции к ряду измельчающихся сеток даёт метод Ромберга.

Числовой пример. Для того же интеграла \(I_h = 0{,}742984\) (n = 4) и \(I_{h/2} = 0{,}745866\) (n = 8), \(p = 2\).
оценка ошибки = (0,745866 − 0,742984)/3 = 9,61·10⁻⁴
уточнение: 0,745866 + 0,000961 = 0,746827
Против точного 0,746824 — ошибка 3·10⁻⁶ вместо 10⁻³ у исходного счёта. Две «дешёвые» суммы дали точность, для которой прямым измельчением потребовалось бы около 300 узлов.

3.5. Квадратуры Гаусса

Если узлы не заданы, а подбираются вместе с весами, то у формулы \(2(n+1)\) свободных параметров, и можно потребовать точности для полиномов степени \(2n+1\). Узлы оказываются корнями полинома Лежандра степени \(n+1\), а формула на отрезке \([-1,1]\) имеет вид

$$\int_{-1}^{1} f(t)\,dt \approx \sum_{i=1}^{n+1} A_i f(t_i),$$

с переносом на произвольный отрезок заменой \(x = \frac{a+b}{2} + \frac{b-a}{2}t\). Уже две точки дают точность для кубических полиномов: \(t_{1,2} = \mp 1/\sqrt3\), \(A_1 = A_2 = 1\).

Числовой пример. Тот же интеграл \(\int_0^1 e^{-x^2}dx\) двухточечной формулой Гаусса. Замена \(x = (1+t)/2\), \(dx = dt/2\); узлы \(t = \mp0{,}577350\) дают \(x_1 = 0{,}211325\), \(x_2 = 0{,}788675\).
\(f(x_1) = e^{-x_1^2}\) = e^(−0,044658) = 0,956324
\(f(x_2) = e^{-x_2^2}\) = e^(−0,622009) = 0,536833
\(I \approx \tfrac12\bigl(f(x_1)+f(x_2)\bigr)\) = 0,5·1,493157 = 0,746578
Две точки дали ошибку 2,5·10⁻⁴ — лучше, чем трапеции на пяти ординатах. Ограничение очевидно: узлы Гаусса не совпадают с табличными, поэтому метод применим, когда функцию можно вычислить в любой точке, а не когда она задана таблицей.

3.6. Интегрирование таблиц: судостроительный случай

В задачах статики корабля подынтегральная функция задана ординатами на равномерной сетке теоретических шпангоутов, и выбора узлов нет. Отсюда повсеместное применение правила трапеций: водоизмещение как интеграл площадей шпангоутов, площадь ватерлинии как интеграл полуширот, моменты инерции ватерлинии. Формально Симпсон точнее, но он требует чётного числа интервалов и «портится» на разрывах — а у корпуса функция \(\omega(x)\) в оконечностях имеет излом.

Полезное свойство трапеций: для периодической гладкой функции, проинтегрированной по целому периоду, формула трапеций имеет не второй порядок, а экспоненциальную сходимость — все члены разложения ошибки взаимно уничтожаются. Этим объясняется, почему интегрирование по углу в задачах качки и по контуру шпангоута даёт неожиданно хорошую точность.

Все три формулы, оценка по Рунге и сравнение сходимости реализованы на странице «Численное интегрирование»; применение к площадям и объёмам корпуса — в курсе статики корабля.

3.6а. Какой формулой считать эту таблицу

Раздел 3.6 объясняет, почему в статике корабля прижились трапеции. Но «прижились» — это традиция, а не алгоритм. Поставим вопрос как в проекте: дана строевая по шпангоутам, 21 ордината на равномерной сетке (20 шпаций), ординаты сняты с теоретического чертежа и содержат погрешность порядка ±0,5 %; надо получить объёмное водоизмещение. Правила Регистра и учебная методика задают требуемую точность результата и ничего не говорят о том, какой квадратурной формулой его получать. Все пять способов ниже применимы к этой таблице и все дают результат в пределах требуемой точности. Алгоритма выбора нет: порядок точности тянет к формулам повыше, изломы строевой — обратно к трапециям, погрешность исходных ординат обесценивает и то и другое, а требование воспроизвести расчёт вручную отбрасывает сплайны. Критерии разнонаправлены — значит, решает не расчёт, а приоритеты.

Чтобы сравнение было не по памяти, а по числам, проведён численный эксперимент. Две тест-функции с известным точным интегралом, обе с \(A_m = 200\) м², \(L = 140\) м, \(\xi = 2x/L - 1\):

$$\omega_1 = A_m (1-\xi^2)^2 e^{0{,}3\xi}, \qquad \omega_2 = \begin{cases} A_m, & |\xi| \le 0{,}35,\\[2pt] A_m\left[1 - \left(\dfrac{|\xi| - 0{,}35}{0{,}65}\right)^{3/2}\right], & |\xi| > 0{,}35. \end{cases}$$

Первая — гладкая строевая судна с заострёнными оконечностями (точное значение 15 029,57 м³). Вторая — судно с цилиндрической вставкой: на плечах производная терпит разрыв, то есть ровно тот излом, о котором говорит раздел 3.6 (точное значение 20 720,00 м³). Устойчивость к погрешности данных проверена отдельно: к каждой ординате добавлялась случайная поправка в пределах ±0,5 %, эксперимент повторялся 5000 раз, и считалось СКО результата.

Во-первых, на гладкой строевой различия между методами не имеют физического смысла: даже худший из них ошибается на 0,003 %, тогда как сами ординаты известны с точностью 0,5 % — метод в сто пятьдесят раз точнее данных. Во-вторых, квадратура Гаусса на изломанной строевой оказывается худшей из всех и вдвое хуже прочих по устойчивости к шуму: узлы Гаусса не совпадают с ординатами таблицы, значения в них приходится брать с интерполянта, и погрешность интерполяции складывается с погрешностью данных.

  • По точности побеждают не трапеции. Если смотреть только на погрешность, лучший вариант — интегрирование кубического сплайна: на изломанной строевой он ошибается в двадцать раз меньше трапеций, а к шуму ординат так же нечувствителен. Трапеции выходят вперёд только тогда, когда прозрачность и свобода по сетке весят вместе больше половины. Именно это и происходит в реальном расчёте статики: результат нужно предъявлять, проверять по строкам и пересчитывать на любой сетке — и за это платят двумя десятыми процента точности.

Ромберг ошибается на гладкой функции на 0,000013 % — в пятьдесят раз точнее трапеций, — но выигрывает, только если вес этого критерия поднять до 0,60 (проверено отдельным прогоном: движок тогда уверенно ставит его первым). А поднимать этот вес нельзя, потому что различие лежит на два порядка ниже погрешности исходных данных. Так метод отношений показывает цену типичной ошибки: гнаться за точностью формулы, когда точность ограничена таблицей.
  • Квадратура Гаусса последняя во всех наборах — и это подтверждает заблуждение, разобранное ниже: для таблицы измерений она неприменима не из-за низкой точности как таковой, а потому что требует значений между узлами, которых у нас нет.
Почему устойчивость к шуму почти одинакова у всех методов?

Потому что все квадратурные формулы — это линейные комбинации ординат с положительными весами, дающими в сумме длину отрезка. Случайные погрешности ординат складываются в сумме как \(\sqrt{\sum c_i^2}\,\sigma\), и пока веса \(c_i\) сопоставимы, результат один и тот же. Выбивается только Гаусс: его значения берутся с интерполянта, а тот усиливает шум соседних узлов. Практический вывод — при неточных данных выбирать формулу надо не по порядку точности, а по тому, не усиливает ли она погрешность.

Заблуждения

  • «Симпсон всегда лучше трапеций». Лучше для гладких функций. При изломе подынтегральной функции внутри пары интервалов четвёртая производная не существует, и порядок падает; выигрыш исчезает.
  • «Уменьшение шага всегда повышает точность». До некоторого предела: при очень мелком шаге начинает доминировать погрешность округления, растущая с числом слагаемых (гл. 1).
  • «Правило Рунге даёт ошибку точно». Оно даёт главный член асимптотической оценки; при слишком грубой сетке эта оценка сама ненадёжна.
  • «Квадратуры Гаусса универсально лучше». Они требуют вычисления функции в произвольных точках. Для таблицы измерений они неприменимы.

Контрольные вопросы

Шаг уменьшили втрое. Во сколько раз упадёт ошибка трапеций и Симпсона?

Трапеции: \(3^2 = 9\) раз. Симпсон: \(3^4 = 81\) раз. Именно поэтому при гладкой функции измельчение сетки для Симпсона окупается быстрее.

Почему формула Симпсона требует чётного числа интервалов?

Она строится по паре интервалов сразу (три ординаты на параболу). При нечётном n последняя тройка не собирается; тогда либо добавляют интервал, либо на последнем участке применяют другую формулу — и порядок точности определяется худшей из них.

Два счёта дали 12,480 и 12,504 при p = 2. Какова оценка ошибки и уточнённое значение?

\((12{,}504 - 12{,}480)/3 = 0{,}008\); уточнение \(12{,}504 + 0{,}008 = 12{,}512\). Ошибка исходного мелкого счёта — около восьми тысячных, то есть 0,06 %.

Почему при интегрировании площадей шпангоутов не гонятся за высокой степенью точности?

Ординаты сняты с теоретического чертежа и сами содержат погрешность порядка миллиметров. Метод точнее данных ничего не добавляет: суммарная погрешность определяется наибольшей составляющей.
