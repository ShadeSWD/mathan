Глава 6. Обыкновенные дифференциальные уравнения

Качка судна, разгон и торможение, остывание отливки, колебания вала — всё это задачи Коши для систем обыкновенных дифференциальных уравнений. Численное решение строится шагами по времени, и главных вопросов два: какой порядок точности даёт метод и не развалится ли счёт при выбранном шаге.

Аналитическая пара главы — «Дифференциальные уравнения». Там задача Коши решается в квадратурах для нескольких распознаваемых типов уравнений; здесь — шагами по сетке для любого уравнения, ценой погрешности метода и требований к устойчивости.

6.1. Задача Коши и сведение к системе первого порядка

Задача Коши: найти \(y(x)\), удовлетворяющую \(y' = f(x, y)\) при \(y(x_0) = y_0\). Уравнение любого порядка сводится к системе первого порядка введением новых неизвестных. Для уравнения колебаний

$$\ddot\theta + 2\nu\dot\theta + \omega^2\theta = M(t)$$

полагаем \(y_1 = \theta\), \(y_2 = \dot\theta\) и получаем

$$\dot y_1 = y_2, \qquad \dot y_2 = M(t) - 2\nu y_2 - \omega^2 y_1 .$$

Поэтому все методы формулируются для системы первого порядка — этого достаточно для любой задачи динамики.

6.2. Методы Эйлера: явный и неявный

$$\text{явный:}\quad y_{k+1} = y_k + h\,f(x_k, y_k), \qquad \text{неявный:}\quad y_{k+1} = y_k + h\,f(x_{k+1}, y_{k+1}).$$

Оба имеют первый порядок точности (\(O(h)\) глобально, \(O(h^2)\) на шаге), но ведут себя принципиально по-разному. Явный требует одного вычисления правой части; неявный — решения уравнения относительно \(y_{k+1}\) (в общем случае нелинейного, см. гл. 4). Зато неявный устойчив там, где явный разваливается.

Явный метод Эйлера идёт по касательной, взятой в начале шага. Каждый шаг уводит от точного решения, и отклонения накапливаются — отсюда первый порядок точности.

6.3. Методы Рунге — Кутты

Идея: вычислить правую часть несколько раз внутри шага и скомбинировать так, чтобы совпали больше членов разложения Тейлора. Классический метод четвёртого порядка:

$$k_1 = f(x_k, y_k), \quad k_2 = f\!\left(x_k + \tfrac{h}{2},\, y_k + \tfrac{h}{2}k_1\right), \quad k_3 = f\!\left(x_k + \tfrac{h}{2},\, y_k + \tfrac{h}{2}k_2\right),$$

$$k_4 = f(x_k + h,\, y_k + h k_3), \qquad y_{k+1} = y_k + \dfrac{h}{6}\bigl(k_1 + 2k_2 + 2k_3 + k_4\bigr).$$

Четыре вычисления правой части на шаг дают глобальную погрешность \(O(h^4)\): уменьшение шага вдвое снижает ошибку в шестнадцать раз. Это соотношение цены и точности и сделало метод стандартом инженерных расчётов.

6.4. Выбор шага и контроль погрешности

Оценка погрешности строится по правилу Рунге, как и в интегрировании (гл. 3): счёт ведут с шагом h и с двумя шагами h/2, и разность результатов делят на \(2^p - 1\). Если оценка меньше допуска — шаг можно увеличить, если больше — уменьшить и повторить. Так работают алгоритмы с автоматическим выбором шага; современные варианты используют вложенные схемы, где две оценки разного порядка получаются из одного набора вычислений.

Практическое правило для колебательных задач: на период собственных колебаний должно приходиться не менее 20–30 шагов. Для качки с периодом 10 с это \(h \leqslant 0{,}3\ldots0{,}5\) с — и именно такой шаг стоит в анимациях курса вибрации.

6.5. Жёсткие системы

Система называется жёсткой, если её решение содержит компоненты с сильно различающимися характерными временами: быстрые процессы затухают почти мгновенно, а нас интересует медленный. Формально — отношение \(|\lambda_{\max}|/|\lambda_{\min}|\) собственных значений матрицы системы велико.

Явные методы на таких задачах требуют шага, определяемого самой быстрой компонентой, даже если она давно затухла. Для модельного уравнения \(y' = \lambda y\) (\(\lambda < 0\)) явный Эйлер даёт \(y_{k+1} = (1 + h\lambda)y_k\), и решение остаётся ограниченным только при

$$|1 + h\lambda| < 1 \quad\Longleftrightarrow\quad h < \dfrac{2}{|\lambda|} .$$

Неявный Эйлер даёт \(y_{k+1} = y_k/(1 - h\lambda)\), и модуль множителя меньше единицы при любом \(h > 0\): метод абсолютно устойчив. Отсюда правило: жёсткие задачи решают неявными методами, платя за это решением системы уравнений на каждом шаге.

Числовой пример. \(y' = -1000y\), интересующий интервал 1 с.
ограничение явного метода: \(h < 2/|\lambda|\) = 2/1000 = 0,002 с
число шагов: 1/0,002 = 500 шагов
Причём уже к \(x = 0{,}01\) решение затухло в \(e^{-10}\) раз, и все оставшиеся 495 шагов считают ноль — но уменьшить шаг нельзя, иначе счёт «взорвётся». Неявный метод пройдёт тот же интервал за 10 шагов.
Так выглядит потеря устойчивости: решение не просто неточно, оно качественно неверно. Признак в расчёте — знакопеременные колебания, растущие от шага к шагу.

6.6. Краевые задачи и метод стрельбы

В краевой задаче условия заданы на обоих концах: например, прогиб балки \(EI\,v^{IV} = q\) с условиями опирания при \(x = 0\) и \(x = L\). Прямое пошаговое интегрирование невозможно — недостаёт условий в начальной точке.

Метод стрельбы сводит краевую задачу к задаче Коши: недостающие начальные условия задают параметром, интегрируют до конца отрезка и сравнивают с требуемым краевым условием. Получается нелинейное уравнение относительно параметра — «промах», который обнуляют методом из гл. 4:

$$\Phi(s) = y(L; s) - y_L = 0 .$$

Альтернатива — конечно-разностный подход: заменить производные разностями во всех узлах сразу и решить получившуюся систему. Для линейной краевой задачи она оказывается трёхдиагональной и решается прогонкой (гл. 5) за \(O(n)\) действий — обычно это и есть предпочтительный путь.

Заблуждения

  • «Метод четвёртого порядка всегда точнее». Порядок — свойство асимптотическое: при слишком большом шаге метод высокого порядка может оказаться хуже, а при потере устойчивости — просто разойтись.
  • «Уменьшение шага всегда улучшает результат». До предела, за которым накопление округлений начинает превышать погрешность метода; оптимальный шаг существует.
  • «Жёсткость — это про нелинейность». Жёсткой может быть и линейная система: дело в разбросе характерных времён, а не в виде правой части.
  • «Неявные методы точнее явных». Неявный Эйлер имеет тот же первый порядок. Он не точнее — он устойчивее.

Контрольные вопросы

Шаг уменьшили вдвое. Во сколько раз упадёт ошибка у методов первого и четвёртого порядка?

В 2 и в 16 раз соответственно. Именно поэтому у метода Рунге — Кутты четырёхкратная стоимость шага окупается почти всегда.

При \(\lambda = -50\) какой максимальный шаг допускает явный метод Эйлера?

\(h < 2/50 = 0{,}04\). При \(h = 0{,}05\) множитель \(|1 + h\lambda| = 1{,}5\), и решение будет расти по модулю, меняя знак каждый шаг.

Как по результатам счёта заметить, что шаг слишком велик?

Два признака: знакопеременные осцилляции с ростом амплитуды (потеря устойчивости) и заметное расхождение решений при шагах h и h/2 (оценка по правилу Рунге превышает допуск).

Почему уравнение качки удобно решать в виде системы двух уравнений первого порядка?

Все стандартные методы формулируются для \(y' = f(x,y)\). Вводя \(y_1 = \theta\) и \(y_2 = \dot\theta\), мы получаем систему, к которой метод Рунге — Кутты применяется покомпонентно без каких-либо изменений — и сразу получаем и угол, и угловую скорость.
