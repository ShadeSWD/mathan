Глава 7. Уравнения в частных производных

Колебания корпуса, распространение тепла при сварке, обтекание тела — всё это уравнения в частных производных. Численно они решаются заменой производных разностями на сетке, и здесь появляется специфическая опасность: схема может быть безупречно аппроксимирующей и при этом давать растущий мусор вместо решения. Отсюда центральное понятие главы — устойчивость.

Аналитическая пара главы — «Функции нескольких переменных» (частные производные) и «Ряды» (ряд Фурье, метод разделения переменных). Там решение уравнения струны — сумма гармоник; здесь — таблица чисел на сетке, зато без требования, чтобы область и краевые условия были «красивыми».

7.1. Классификация и три типа задач

Линейное уравнение второго порядка \(Au_{xx} + 2Bu_{xy} + Cu_{yy} + \dots = 0\) классифицируется по знаку дискриминанта \(B^2 - AC\):

ТипПризнакПримерПостановка
гиперболический\(B^2 - AC > 0\) колебания струны \(u_{tt} = a^2 u_{xx}\) начальные условия + краевые, решение переносится волнами
параболический\(B^2 - AC = 0\) теплопроводность \(u_t = a^2 u_{xx}\) начальное условие + краевые, решение сглаживается со временем
эллиптический\(B^2 - AC < 0\) уравнение Лапласа \(u_{xx} + u_{yy} = 0\) только краевые условия, задача стационарная

Тип определяет и физику, и метод: в гиперболических задачах возмущение распространяется с конечной скоростью, в параболических — мгновенно «размазывается», в эллиптических времени нет вовсе, и решение в каждой точке зависит от всей границы сразу.

7.2. Разностная сетка и аппроксимация производных

Вводят сетку \(x_i = i\,h\), \(t_k = k\,\tau\) и обозначают \(u_i^k \approx u(x_i, t_k)\). Производные заменяют разностями, чей порядок аппроксимации следует из разложения Тейлора:

$$u_x \approx \dfrac{u_{i+1} - u_i}{h}\ \ (O(h)), \qquad u_x \approx \dfrac{u_{i+1} - u_{i-1}}{2h}\ \ (O(h^2)),$$

$$u_{xx} \approx \dfrac{u_{i+1} - 2u_i + u_{i-1}}{h^2}\ \ (O(h^2)).$$

Схема аппроксимирует уравнение с порядком \((p, q)\), если невязка от подстановки точного решения имеет порядок \(O(h^p + \tau^q)\). Аппроксимация — необходимое, но недостаточное условие пригодности схемы.

7.3. Уравнение теплопроводности: явная и неявная схемы

Для \(u_t = a^2 u_{xx}\) простейшая явная схема:

$$\dfrac{u_i^{k+1} - u_i^{k}}{\tau} = a^2\,\dfrac{u_{i+1}^{k} - 2u_i^{k} + u_{i-1}^{k}}{h^2},$$

откуда значение на новом слое выражается явно через старый:

$$u_i^{k+1} = u_i^{k} + \sigma\bigl(u_{i+1}^{k} - 2u_i^{k} + u_{i-1}^{k}\bigr), \qquad \sigma = \dfrac{a^2\tau}{h^2}.$$

Схема проста, но устойчива только при \(\sigma \leqslant 1/2\), то есть \(\tau \leqslant h^2/(2a^2)\). Ограничение жестокое: измельчение сетки вдвое требует уменьшения шага по времени вчетверо.

Неявная схема берёт пространственные разности на новом слое:

$$\dfrac{u_i^{k+1} - u_i^{k}}{\tau} = a^2\,\dfrac{u_{i+1}^{k+1} - 2u_i^{k+1} + u_{i-1}^{k+1}}{h^2}.$$

Теперь на каждом шаге решается система относительно всего слоя, но система трёхдиагональная — прогонка справляется за \(O(n)\) (гл. 5). Взамен схема абсолютно устойчива: шаг по времени выбирается из соображений точности, а не устойчивости. Симметричная комбинация обеих (схема Кранка — Николсон) даёт второй порядок по времени и тоже абсолютно устойчива.

Шаблоны схем. Явная считает узлы нового слоя по отдельности, неявная связывает их в систему — и именно эта связь даёт безусловную устойчивость.
Числовой пример. Сварка: \(a^2 = 8\cdot10^{-6}\) м²/с (сталь), сетка h = 2 мм.
\(\tau \leqslant h^2/(2a^2)\) = (0,002)²/(2·8·10⁻⁶) = 0,25 с
Для расчёта охлаждения за 60 с нужно 240 шагов — терпимо. Но при сетке h = 0,5 мм ограничение падает до 0,0156 с, и шагов становится 3 840: работа вырастает в 64 раза при уменьшении шага сетки вчетверо. Здесь и переходят к неявной схеме.

7.4. Уравнение колебаний и условие Куранта

Для \(u_{tt} = a^2 u_{xx}\) явная схема «крест» даёт

$$u_i^{k+1} = 2u_i^{k} - u_i^{k-1} + C^2\bigl(u_{i+1}^{k} - 2u_i^{k} + u_{i-1}^{k}\bigr), \qquad C = \dfrac{a\,\tau}{h}.$$

Величину C называют числом Куранта, а условие устойчивости — условием Куранта — Фридрихса — Леви:

$$C = \dfrac{a\,\tau}{h} \leqslant 1 .$$

Физический смысл прозрачен: \(a\tau\) — расстояние, которое волна проходит за шаг по времени; условие требует, чтобы оно не превышало шага сетки. Иначе численная область зависимости оказывается уже физической: схема «не успевает» узнать о возмущении, которое обязано было прийти, — и решение разрушается.

Условие Куранта геометрически. Численная область зависимости должна включать физическую: схема обязана «видеть» всё, что влияет на решение в узле.
Числовой пример. Струна длиной 1 м, \(a = 200\) м/с, сетка из 100 интервалов (h = 0,01 м).
\(\tau \leqslant h/a\) = 0,01/200 = 5·10⁻⁵ с
шагов на 1 с процесса: 1/5·10⁻⁵ = 20 000
Причём при \(C = 1\) ровно схема оказывается не только устойчивой, но и точной для этого уравнения — редкий случай, когда предельное значение параметра является наилучшим.

7.5. Аппроксимация, устойчивость, сходимость

Три понятия связаны фундаментальным результатом (теорема эквивалентности Лакса): для корректно поставленной линейной задачи из аппроксимации и устойчивости следует сходимость. Практический смысл этого утверждения велик: сходимость проверить напрямую нельзя (точное решение неизвестно), а аппроксимацию и устойчивость — можно.

СвойствоЧто означаетКак проверяется
аппроксимациясхема приближает уравнение при \(h,\tau\to0\) подстановка точного решения и разложение по Тейлору
устойчивостьпогрешности не нарастают от слоя к слою спектральный признак: множитель перехода по модулю не больше единицы
сходимостьчисленное решение стремится к точному следует из двух предыдущих

Спектральный признак устойчивости (метод гармоник) работает так: в схему подставляют \(u_i^k = \rho^{k} e^{\,\mathrm{i}\varphi i}\) и требуют \(|\rho| \leqslant 1\) для всех \(\varphi\). Для явной схемы теплопроводности это условие в точности даёт \(\sigma \leqslant 1/2\), для схемы «крест» — \(C \leqslant 1\).

7.6. Практика: на что смотреть в расчёте

  • Признак неустойчивости — знакопеременные осцилляции, растущие от шага к шагу, обычно начинающиеся у границы. Это не «шум», а разрушение счёта: уменьшайте шаг по времени или переходите к неявной схеме.
  • Признак избыточной диффузии — гладкое решение там, где ожидался фронт. Схемы первого порядка по пространству вносят численную вязкость, сглаживающую разрывы.
  • Проверка на законе сохранения: посчитайте полную энергию или полное количество тепла на каждом слое. Систематический дрейф — признак ошибки в схеме или в краевых условиях.
  • Проверка на точном решении: почти у каждой модельной задачи оно есть (стоячая волна, распространение тепла в полубесконечном стержне) — прогоните схему на ней и убедитесь, что порядок сходимости соответствует теоретическому.

Явная схема для уравнения колебаний струны с наблюдением за устойчивостью реализована на странице «Колебания струны»; физическая сторона задачи — в курсе вибрации.

Заблуждения

  • «Схема аппроксимирует уравнение — значит, даст решение». Без устойчивости аппроксимация бесполезна: погрешность растёт быстрее, чем убывает невязка.
  • «Неявные схемы точнее». Неявная схема первого порядка по времени точно так же имеет первый порядок. Она устойчивее, а не точнее.
  • «Условие Куранта — техническая формальность». Это физическое требование: численная область зависимости должна включать физическую.
  • «Измельчение сетки всегда улучшает решение». Для явной схемы теплопроводности уменьшение h вдвое требует уменьшения \(\tau\) вчетверо; без этого решение не улучшится, а разрушится.

Контрольные вопросы

Сетку по пространству измельчили втрое. Как изменится допустимый шаг по времени для явной схемы теплопроводности?

\(\tau \leqslant h^2/(2a^2)\), значит уменьшится в девять раз, а общее число шагов вырастет в девять раз при том же интервале времени. Суммарная работа растёт в 27 раз с учётом увеличения числа узлов.

При \(a = 340\) м/с и h = 0,05 м каков предельный шаг по времени для схемы «крест»?

\(\tau \leqslant h/a = 0{,}05/340 = 1{,}47\cdot10^{-4}\) с. При \(\tau = 2\cdot10^{-4}\) с получим \(C = 1{,}36 > 1\) — счёт разрушится за несколько десятков шагов.

Почему у эллиптических задач нет условия устойчивости по времени?

Времени в них нет: решение определяется краевыми условиями сразу во всей области. Разностная аппроксимация даёт одну большую систему линейных уравнений, и вопрос устойчивости заменяется вопросом обусловленности этой системы.

В расчёте появились «зубцы» через один узел, растущие со временем. Диагноз?

Классическая картина неустойчивости: гармоника с наибольшей частотой, представимой на сетке (\(\varphi = \pi\)), имеет множитель перехода больше единицы. Нужно уменьшить шаг по времени до выполнения условия устойчивости или перейти на неявную схему.
