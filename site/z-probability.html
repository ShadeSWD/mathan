Задачи: вероятность и статистика

Девять заданий типового расчёта кафедры, разобранных по шагам с теми числами, которые стоят в вариантах. Порядок задач повторяет порядок разделов главы 9: сначала подсчёт вероятностей событий, затем случайные величины, затем обработка реальной выборки из пятидесяти измерений. Все значения функции Лапласа и коэффициенты Стьюдента взяты из таблиц, приведённых в конспекте лекций кафедры, а вся арифметика пересчитана заново.

Коротко

Разобраны девять типов заданий: комбинаторный подсчёт, надёжность схемы, формула Байеса, приближения схемы Бернулли, дискретная и непрерывная случайные величины, нормальный закон, первичная обработка выборки и доверительный интервал.

  • Классическая вероятность: свести задачу к подсчёту сочетаний и не забыть, что сумма вероятностей полной группы равна единице.
  • Схема надёжности: последовательное соединение — произведение, параллельное — правило «хотя бы один» через противоположное событие.
  • Гипотезы — причины, наблюдаемое событие — следствие; вопрос «какова вероятность» решается формулой полной вероятности, вопрос «откуда» — формулой Байеса.
  • Приближение выбирается по числам, а не по вкусу: при малом \(np\) — Пуассон, при большом \(npq\) — Лаплас.
  • Для непрерывной величины первое действие всегда одно: найти константу из условия нормировки \(\int f(x)\,dx=1\).
  • В статистике различаются выборочная и исправленная дисперсии; в доверительный интервал входит исправленная.

Проверка в каждой задаче независимая: сумма вероятностей равна единице, интеграл плотности равен единице, \(F'(x)\) совпадает с \(f(x)\), приближённая формула сверяется с точной, доверительный интервал — с оценкой по несгруппированным данным.

Задача 1. Классическая вероятность и комбинаторика

Задача 1. Два шара из урны

Дано: в урне 6 белых и 4 чёрных шара, одновременно извлекают два шара. Найти вероятности событий: а) оба шара чёрные; б) один чёрный, другой белый; в) хотя бы один шар белый.
Шары извлекаются одновременно, поэтому порядок не важен: элементарный исход — неупорядоченная пара шаров. Общее число исходов равно числу сочетаний из десяти по два.
\(n=C_{10}^{2}=\dfrac{10!}{2!\,8!}\) = (10 · 9)/2 = 45
а) Благоприятные исходы — пары, целиком составленные из чёрных шаров; их \(C_4^2\).
\(P(A)=\dfrac{C_4^2}{C_{10}^2}\) = 6/45 = 2/15 ≈ 0,1333
б) Пару «чёрный и белый» составляют, выбирая один чёрный из четырёх и один белый из шести; по принципу умножения число таких пар равно произведению.
\(P(B)=\dfrac{C_4^1 C_6^1}{C_{10}^2}\) = (4 · 6)/45 = 24/45 = 8/15 ≈ 0,5333
в) «Хотя бы один белый» — событие, противоположное событию «оба чёрные». Считать через дополнение короче, чем складывать два слагаемых.
\(P(C)=1-P(A)\) = 1 − 2/15 = 13/15 ≈ 0,8667
\(P(A)=2/15\approx 0{,}1333\); \(P(B)=8/15\approx 0{,}5333\); \(P(C)=13/15\approx 0{,}8667\).
число чёрных шаров в паре принимает три значения, и соответствующие события образуют полную группу: \(C_4^2/45+C_4^1C_6^1/45+C_6^2/45=6/45+24/45+15/45=1\) — сумма равна единице, значит ни один исход не потерян и не посчитан дважды. Ответ (а) подтверждается и независимым подсчётом с учётом порядка: вероятность взять подряд два чёрных шара равна \(\frac{4}{10}\cdot\frac{3}{9}=\frac{12}{90} =\frac{2}{15}\) — то же число, как и должно быть, потому что при переходе к упорядоченным исходам и числитель, и знаменатель умножаются на \(2!\).

Задача 2. Теоремы сложения и умножения: надёжность схемы

Задача 2. Три элемента схемы

Дано: элементы работают независимо, вероятности их безотказной работы \(p_1=0{,}9\), \(p_2=0{,}8\), \(p_3=0{,}6\). Элемент 1 включён последовательно с параллельным блоком из элементов 2 и 3. Найти: а) вероятность безотказной работы схемы; б) вероятность того, что откажет ровно один элемент.
Параллельный блок отказывает только при отказе обоих элементов сразу. Считаем через противоположное событие.
\(P_{23}=1-(1-p_2)(1-p_3)\) = 1 − 0,2 · 0,4 = 1 − 0,08 = 0,92
Последовательное соединение требует работы обоих участков одновременно — теорема умножения для независимых событий.
\(P_{\text{сх}}=p_1\,P_{23}\) = 0,9 · 0,92 = 0,828
б) Событие «откажет ровно один» распадается на три несовместных случая по номеру отказавшего элемента; вероятность каждого считается теоремой умножения, затем складываются.
\(q_1p_2p_3+p_1q_2p_3+p_1p_2q_3\) = 0,1·0,8·0,6 + 0,9·0,2·0,6 + 0,9·0,8·0,4 = 0,048 + 0,108 + 0,288 = 0,444
схема работает с вероятностью 0,828; ровно один элемент отказывает с вероятностью 0,444.
число отказавших элементов принимает значения 0, 1, 2, 3, и эти события образуют полную группу. Вероятность нуля отказов \(0{,}9\cdot0{,}8\cdot0{,}6=0{,}432\); двух отказов \(0{,}072+0{,}032+0{,}012=0{,}116\); трёх — \(0{,}1\cdot0{,}2\cdot0{,}4=0{,}008\). Сумма \(0{,}432+0{,}444+0{,}116+0{,}008=1{,}000\), контроль пройден. Ответ (а) правдоподобен и по порядку величины: схема заведомо надёжнее, чем при последовательном соединении всех трёх элементов (0,432), и заведомо ненадёжнее самого элемента 1 (0,9); полученные 0,828 лежат между этими границами.

Задача 3. Формула полной вероятности и формула Байеса

Задача 3. Лампы трёх партий

Дано: из 1000 ламп 200 принадлежат первой партии, 300 — второй, 500 — третьей; брак составляет 6 %, 5 % и 4 % соответственно. Найти: а) вероятность того, что наудачу выбранная лампа бракованная; б) вероятность того, что бракованная лампа принадлежит третьей партии.
Гипотезы — принадлежность лампы партии; их априорные вероятности равны долям партий в общем количестве.
\(P(H_1),P(H_2),P(H_3)\) = 200/1000; 300/1000; 500/1000 = 0,2; 0,3; 0,5
Условные вероятности события \(A\) («лампа бракованная») заданы процентами брака в партиях.
\(P(A\mid H_1),P(A\mid H_2),P(A\mid H_3)\) = 0,06; 0,05; 0,04 = заданы условием
а) Формула полной вероятности: складываем вклады всех трёх ветвей.
\(P(A)=\sum P(H_i)P(A\mid H_i)\) = 0,2·0,06 + 0,3·0,05 + 0,5·0,04 = 0,012 + 0,015 + 0,020 = 0,047
б) Формула Байеса: доля третьей ветви в полученной сумме.
\(P(H_3\mid A)=\dfrac{P(H_3)P(A\mid H_3)}{P(A)}\) = 0,020 / 0,047 = 20/47 = ≈ 0,4255
Вклад каждой партии в общий брак — произведение двух чисел вдоль ветви. Третья партия даёт наибольший вклад не из-за высокого процента брака (он как раз наименьший), а из-за объёма: половина всех ламп. Именно это и показывает формула Байеса.
вероятность купить бракованную лампу равна 0,047; вероятность того, что бракованная лампа из третьей партии, равна \(20/47\approx 0{,}4255\).
апостериорные вероятности всех трёх гипотез в сумме обязаны давать единицу: \(\frac{12}{47}+\frac{15}{47}+\frac{20}{47}=\frac{47}{47}=1\). Второй контроль — на порядок величины: \(P(A)\) есть среднее взвешенное чисел 0,06, 0,05 и 0,04 и потому обязано лежать между наименьшим и наибольшим из них; полученное 0,047 этому условию удовлетворяет и, как и следовало ожидать, ближе к 0,04, поскольку у третьей партии наибольший вес.

Задача 4. Схема Бернулли и выбор приближения

Задача 4. Две партии изделий

Дано: а) в партии \(n=500\) изделий, вероятность брака каждого \(p=0{,}008\); б) в другой партии \(n=400\) изделий, вероятность брака \(p=0{,}5\). Найти: а) вероятность того, что бракованных изделий не более двух, и наивероятнейшее их число; б) вероятность того, что число бракованных заключено между 190 и 210. В каждом случае обосновать выбор приближённой формулы.
а) Проверяем условия применимости. Испытаний много, вероятность мала, произведение \(np\) умеренно — это область формулы Пуассона, а не Лапласа (\(npq\) слишком мало).
\(\lambda=np,\quad npq\) = 500 · 0,008 = 4; npq = 4 · 0,992 = 3,97 < 9 = λ = 4, применяем Пуассона
Складываем три пуассоновские вероятности: ни одного, одно и два бракованных изделия.
\(P(k\le 2)=e^{-\lambda}\left(1+\lambda+\dfrac{\lambda^2}{2}\right)\) = e⁻⁴ · (1 + 4 + 8) = 13 · 0,018316 = 0,2381
Наивероятнейшее число успехов находим из двойного неравенства \(np-q\le k_0\le np+p\).
\(np-q\le k_0\le np+p\) = 3,008 ≤ k₀ ≤ 4,008 = k₀ = 4
б) Здесь \(p\) не мало, зато \(npq\) велико — работает интегральная теорема Лапласа. Считаем сначала \(\sigma\).
\(\sqrt{npq}\) = √(400 · 0,5 · 0,5) = √100 = 10
Переводим границы в стандартные единицы и берём значения функции Лапласа по таблице.
\(\Phi\!\left(\frac{210-200}{10}\right)-\Phi\!\left(\frac{190-200}{10}\right)\) = Φ(1) − Φ(−1) = 2 · 0,3413 = 0,6827
а) \(P(k\le 2)\approx 0{,}238\), наивероятнейшее число бракованных \(k_0=4\); б) \(P(190\le k\le 210)\approx 0{,}683\).
обе приближённые формулы сверяем с точным расчётом по формуле Бернулли. В случае (а) точное значение \(\sum_{k=0}^{2}C_{500}^k(0{,}008)^k(0{,}992)^{500-k}=0{,}23693\) против пуассоновского 0,23810 — расхождение 0,5 %, приближение оправдано. В случае (б) точное значение равно 0,70629, а формула Лапласа дала 0,68269 — расхождение уже 3,3 %, и причина известна: непрерывной кривой заменяется ступенчатое распределение, а границы 190 и 210 попадают ровно на «ступеньки». Поправка на непрерывность, то есть замена границ на 189,5 и 210,5, даёт \(2\Phi(1{,}05)=2\cdot 0{,}3531=0{,}7062\) — совпадение с точным значением до четвёртого знака. Это и подтверждает, что расхождение вызвано не ошибкой в вычислениях, а самой природой приближения.

Задача 5. Дискретная случайная величина

Задача 5. Число попаданий при атаке четырьмя торпедами

Дано: вероятность поражения цели одной торпедой \(p=0{,}4\), выпущено четыре торпеды независимо; \(X\) — число попаданий. Найти: ряд распределения, функцию распределения и её график, \(M[X]\), \(D[X]\), \(\sigma_X\), моду и медиану, вероятность \(P\{X\le 2\}\).
Испытания независимы и однотипны — схема Бернулли, \(n=4\), \(q=0{,}6\). Вероятности считаем по формуле Бернулли.
\(p_k=C_4^k\,0{,}4^k\,0{,}6^{4-k}\) = 0,1296; 4·0,4·0,216; 6·0,16·0,36; 4·0,064·0,6; 0,0256 = 0,1296; 0,3456; 0,3456; 0,1536; 0,0256
Функция распределения \(F(x)=P\{X<x\}\) — накопленные суммы; она постоянна между значениями и скачет в самих значениях на величину \(p_k\).
\(F(1),F(2),F(3),F(4)\) = 0,1296; 0,1296+0,3456; +0,3456; +0,1536 = 0,1296; 0,4752; 0,8208; 0,9744
Математическое ожидание — сумма произведений значений на вероятности.
\(M[X]=\sum k\,p_k\) = 0·0,1296 + 1·0,3456 + 2·0,3456 + 3·0,1536 + 4·0,0256 = 1,6
Дисперсию считаем через второй начальный момент — так короче, чем по определению.
\(D[X]=M[X^2]-(M[X])^2\) = 3,52 − 1,6²= 3,52 − 2,56 = 0,96
Среднее квадратическое отклонение — корень из дисперсии; оно измеряется в тех же единицах, что и само число попаданий.
\(\sigma_X=\sqrt{D[X]}\) = √0,96 = ≈ 0,9798
Мода — значение с наибольшей вероятностью; здесь максимум достигается дважды. Медиана — первое значение, на котором накопленная вероятность достигает 0,5.
\(p_1=p_2=0{,}3456\); \(F(2)=0{,}4752<0{,}5\le F(3)=0{,}8208\) = две моды; медиана — значение 2 = xmod = 1 и 2, xmed = 2
Вероятность \(P\{X\le 2\}\) — накопленная сумма трёх первых вероятностей, то есть \(F(3)\).
\(P\{X\le 2\}=p_0+p_1+p_2\) = 0,1296 + 0,3456 + 0,3456 = 0,8208
График \(F(x)\) для \(X\sim\mathrm{Bi}(4;\,0{,}4)\). Ступени постоянны между целыми значениями: у дискретной величины между точками роста ничего не происходит. Заполненный кружок показывает, какое значение функция принимает в точке скачка при определении \(F(x)=P\{X<x\}\).
ряд распределения 0,1296; 0,3456; 0,3456; 0,1536; 0,0256; \(M[X]=1{,}6\), \(D[X]=0{,}96\), \(\sigma_X\approx 0{,}98\); две моды 1 и 2, медиана 2; \(P\{X\le 2\}=0{,}8208\).
сумма вероятностей ряда \(0{,}1296+0{,}3456+0{,}3456+0{,}1536+0{,}0256=1{,}0000\) — условие нормировки выполнено. Независимая проверка характеристик: для биномиального распределения существуют готовые формулы \(M[X]=np\) и \(D[X]=npq\), не использованные при счёте. Они дают \(4\cdot 0{,}4=1{,}6\) и \(4\cdot0{,}4\cdot0{,}6=0{,}96\) — совпадение полное, значит и ряд, и арифметика верны. Наконец, \(M[X]=1{,}6\) лежит внутри диапазона значений \([0;4]\) и ближе к его левому краю, что согласуется с \(p<0{,}5\).

Задача 6. Непрерывная случайная величина

Задача 6. Плотность с неизвестным параметром

Дано: плотность распределения \(f(x)=Axe^{-x^2}\) при \(x>0\) и \(f(x)=0\) при \(x\le 0\). Найти: параметр \(A\), функцию распределения \(F(x)\), \(M[X]\), \(D[X]\), \(\sigma_X\), моду и медиану, вероятность \(P\{0{,}5<X<1{,}5\}\).
Параметр всегда находится из условия нормировки: полная площадь под плотностью равна единице. Интеграл берётся подведением под знак дифференциала, поскольку \(x\,dx=\tfrac12 d(x^2)\).
\(\displaystyle\int_0^{\infty}Axe^{-x^2}dx =\frac{A}{2}\Bigl[-e^{-x^2}\Bigr]_0^{\infty}=\frac{A}{2}=1\) = A/2 = 1 = A = 2
Функция распределения — интеграл от плотности с переменным верхним пределом.
\(\displaystyle F(x)=\int_0^{x}2te^{-t^2}dt\) = [−e^(−t²)] от 0 до x = F(x) = 1 − e−x² при x ≥ 0
Математическое ожидание — интеграл от \(xf(x)\); он берётся по частям и сводится к интегралу Пуассона \(\int_0^\infty e^{-x^2}dx=\sqrt{\pi}/2\).
\(\displaystyle M[X]=\int_0^{\infty}2x^2e^{-x^2}dx\) = 2 · (√π)/4 = √π/2 ≈ 0,8862
Второй начальный момент считается тем же подведением под дифференциал с последующим интегрированием по частям.
\(\displaystyle M[X^2]=\int_0^{\infty}2x^3e^{-x^2}dx\) = замена u = x², ∫₀^∞ u e^(−u) du = 1
Дисперсия и СКВО получаются из уже найденных моментов.
\(D[X]=M[X^2]-(M[X])^2\) = 1 − π/4 = 1 − 0,7854 = 0,2146; σ ≈ 0,4633
Мода — точка максимума плотности; приравниваем нулю производную \(f'(x)=2e^{-x^2}(1-2x^2)\).
\(1-2x^2=0\) = x = 1/√2 = xmod ≈ 0,7071
Медиана — корень уравнения \(F(x)=0{,}5\).
\(1-e^{-x^2}=0{,}5\) = x = √(ln 2) = √0,6931 = xmed ≈ 0,8326
Вероятность попадания в промежуток — приращение функции распределения (оно же площадь под плотностью).
\(P=F(1{,}5)-F(0{,}5)=e^{-0{,}25}-e^{-2{,}25}\) = 0,7788 − 0,1054 = 0,6734
Плотность обращается в нуль в начале координат, растёт до моды \(1/\sqrt2\) и затем убывает с «тяжеловатым» правым хвостом. Именно поэтому мода меньше медианы, а медиана меньше математического ожидания: распределение скошено вправо.
\(A=2\); \(F(x)=1-e^{-x^2}\) при \(x\ge 0\); \(M[X]=\sqrt{\pi}/2\approx 0{,}8862\), \(D[X]=1-\pi/4\approx 0{,}2146\), \(\sigma_X\approx 0{,}4633\); \(x_{\text{mod}}\approx 0{,}7071\), \(x_{\text{med}}\approx 0{,}8326\); \(P\{0{,}5<X<1{,}5\}\approx 0{,}6734\).
три независимых контроля. Во-первых, найденная \(F(x)\) удовлетворяет обязательным условиям: \(F(0)=0\) и \(F(+\infty)=1-e^{-\infty}=1\) — значит нормировка не нарушена. Во-вторых, дифференцирование возвращает исходную плотность: \(F'(x)=\bigl(1-e^{-x^2}\bigr)'=2xe^{-x^2}=f(x)\) — согласованность \(F\) и \(f\) подтверждена. В-третьих, вероятность, посчитанная как приращение \(F\), должна совпасть с прямым интегрированием плотности: \(\int_{0,5}^{1,5}2xe^{-x^2}dx=\bigl[-e^{-x^2}\bigr]_{0,5}^{1,5} =e^{-0,25}-e^{-2,25}=0{,}6734\) — совпадает. Дополнительно проверяется взаимное расположение характеристик положения: \(0{,}7071<0{,}8326<0{,}8862\), то есть мода \(<\) медиана \(<\) математическое ожидание, что и должно быть у распределения с правой асимметрией.

Задача 7. Нормальное распределение и правило трёх сигм

Задача 7. Допуск на диаметр вала

Дано: диаметр вала \(X\) распределён нормально с параметрами \(a=30\) мм и \(\sigma=0{,}2\) мм; вал годен, если его диаметр отличается от номинала не более чем на 0,5 мм. Найти: а) вероятность того, что вал годен; б) практический диапазон значений диаметра по правилу трёх сигм; в) вероятность того, что все пять проверенных валов годны.
Промежуток симметричен относительно \(a\), поэтому применима формула \(P\{|X-a|<\delta\}=2\Phi(\delta/\sigma)\). Переводим допуск в стандартные единицы.
\(\delta/\sigma\) = 0,5 / 0,2 = 2,5
Значение функции Лапласа берём по таблице конспекта кафедры и удваиваем.
\(P=2\Phi(2{,}5)\) = 2 · 0,4938 = 0,9876
б) Правило трёх сигм даёт практический диапазон значений: за его пределы величина выходит примерно в трёх случаях из тысячи.
\((a-3\sigma;\ a+3\sigma)\) = (30 − 0,6; 30 + 0,6) = (29,4; 30,6) мм
в) Проверки независимы, поэтому событие «все пять годны» — произведение пяти независимых событий.
\(P_5=p^5\) = 0,9876⁵ = ≈ 0,9394
Допуск (зелёный отрезок) уже, чем интервал трёх сигм (красный пунктир), поэтому часть валов неизбежно выходит за допуск. Чтобы доля брака стала пренебрежимо малой, нужно уменьшить \(\sigma\) — то есть улучшить технологию, а не изменять допуск.
вал годен с вероятностью 0,9876; практический диапазон диаметров (29,4; 30,6) мм; все пять валов годны с вероятностью \(\approx 0{,}9394\).
контроль по правилу трёх сигм. Полученному допуску отвечает \(\delta=2{,}5\sigma\), то есть промежуток уже, чем \(\pm3\sigma\); значит найденная вероятность обязана быть меньше табличного значения \(2\Phi(3)=0{,}9973\) — и действительно \(0{,}9876<0{,}9973\). Доля брака составляет \(1-0{,}9876=0{,}0124\), то есть 1,24 %, тогда как при допуске \(\pm3\sigma\) она была бы 0,27 % — качественная зависимость «уже допуск, больше брака» соблюдена. Ответ (в) проверяется через противоположное событие: хотя бы один бракованный вал среди пяти встречается с вероятностью \(1-0{,}9394=0{,}0606\), что примерно впятеро больше доли брака в одном испытании (\(5\cdot 0{,}0124=0{,}062\)) — так и должно быть при малой вероятности брака.

Задача 8. Первичная обработка выборки

Задача 8. Пятьдесят измерений

Дано: выборка объёма \(n=50\) из типового расчёта по математической статистике (значения в порядке записи протокола): −1,4 3,9 13,8 −3,6 13,7 −0,3 6,4 8,5 8,7 14,7 7,6 7,5 18,4 14,3 1,9 7,2 −1,7 1,5 9,7 1,7 12,3 8,4 −1,7 8,4 16,9 13,9 7,7 11,6 3,6 4,2 3,3 8,8 5,4 17,5 13,4 18,5 1,9 6,9 4,8 6,2 6,2 2,1 4,9 6,5 1,0 10,6 3,2 10,0 17,6 9,0. Найти: вариационный ряд, интервальный статистический ряд, гистограмму, выборочное среднее, выборочную и исправленную выборочную дисперсии.
Упорядочиваем выборку. Крайние члены вариационного ряда дают диапазон и размах.
\(R=x_n^*-x_1^*\) = 18,5 − (−3,6) = 22,1
Число интервалов берём по рекомендации конспекта кафедры \(l=[1+3{,}32\lg n]\); длину интервала округляем в бо́льшую сторону, чтобы последняя граница накрыла максимум выборки.
\(l=[1+3{,}32\lg 50]\), \(h=R/l\) = [6,64] = 6; 22,1/6 = 3,683 → 3,7 = l = 6, h = 3,7
Границы интервалов отсчитываем от минимума: \(a_i=a_0+ih\). Подсчитываем, сколько значений попало в каждый полуоткрытый интервал.
\(a_i\): −3,6; 0,1; 3,8; 7,5; 11,2; 14,9; 18,6 = ni = 5; 9; 11; 12; 8; 5 = Σni = 50
Частоты \(p_i^*=n_i/n\) и значения гистограммы \(p_i^*/h\); середины интервалов \(\tilde x_i\) понадобятся для характеристик.
\(p_i^*\) = 0,10; 0,18; 0,22; 0,24; 0,16; 0,10 = Σpi* = 1
Выборочное среднее считаем по группированному ряду: каждое значение заменяется серединой своего интервала.
\(\overline{x}=\sum\tilde x_i p_i^*\) = −1,75·0,10 + 1,95·0,18 + 5,65·0,22 + 9,35·0,24 + 13,05·0,16 + 16,75·0,10 = 7,426
Выборочная дисперсия — через второй момент группированного ряда.
\(s^2_{\text{в}}=\sum\tilde x_i^2p_i^*-\overline{x}^{\,2}\) = 84,2997 − 7,426² = 84,2997 − 55,1454 = 29,1542
Исправленная выборочная дисперсия и исправленное СКВО: именно они несмещённые и именно они пойдут в доверительный интервал.
\(s^2=\dfrac{n}{n-1}s^2_{\text{в}}\) = (50/49) · 29,1542 = 29,7492 = s ≈ 5,4543
Гистограмма одновершинна и почти симметрична, а наложенная нормальная кривая проходит близко к вершинам столбиков — это основание выдвинуть гипотезу о нормальном законе и проверить её критерием Пирсона (\(\chi^2_{\text{набл}}=0{,}50\) при критическом значении 7,81 для трёх степеней свободы, гипотеза принимается).
\(R=22{,}1\), \(l=6\), \(h=3{,}7\); \(n_i=5;9;11;12;8;5\); \(\overline{x}=7{,}426\), \(s^2_{\text{в}}=29{,}15\), \(s^2=29{,}75\), \(s\approx 5{,}454\).
три контроля. Сумма частот \(0{,}10+0{,}18+0{,}22+0{,}24+0{,}16+0{,}10=1{,}00\), а суммарная площадь столбиков равна \(\sum(p_i^*/h)\cdot h=\sum p_i^*=1\) — гистограмма нормирована правильно. Далее, характеристики посчитаны по группированному ряду, поэтому их сверяем с прямым расчётом по всем пятидесяти исходным значениям: он даёт \(\overline{x}=7{,}512\) и \(s=5{,}691\). Расхождение составляет 1 % по среднему и 4 % по СКВО, что как раз и есть цена замены значений серединами интервалов шириной 3,7. Наконец, выборочная медиана равна 7,35 и почти совпадает с выборочным средним 7,43 — признак симметричного распределения, согласующийся с видом гистограммы.

Задача 9. Доверительный интервал для математического ожидания

Задача 9. Точность оценки среднего

Дано: та же выборка объёма \(n=50\) из задачи 8, \(\overline{x}=7{,}426\), исправленное выборочное СКВО \(s=5{,}454\); генеральное распределение принято нормальным, СКВО генеральной совокупности неизвестно. Найти: доверительный интервал для математического ожидания при надёжности \(\beta=0{,}95\).
Так как \(\sigma\) неизвестно и заменено выборочной оценкой, коэффициент берётся из таблицы распределения Стьюдента по числу степеней свободы \(m=n-1\).
\(m=n-1,\quad t_{m,\beta}\) = m = 49; по таблице при β = 0,95 = t = 2,0096
Точность оценки — половина ширины интервала.
\(\varepsilon=\dfrac{s}{\sqrt{n}}\,t_{m,\beta}\) = (5,4543 / 7,0711) · 2,0096 = 0,7714 · 2,0096 = 1,5501
Записываем интервал, симметричный относительно выборочного среднего.
\((\overline{x}-\varepsilon;\ \overline{x}+\varepsilon)\) = (7,426 − 1,550; 7,426 + 1,550) = (5,876; 8,976)
Интервал симметричен относительно выборочного среднего, его полуширина \(\varepsilon\) убывает как \(1/\sqrt{n}\). Синяя точка — оценка среднего по несгруппированным данным: она лежит внутри интервала, и это первый признак того, что расчёт не содержит грубой ошибки.
с надёжностью 0,95 математическое ожидание заключено в интервале (5,876; 8,976); точность оценки \(\varepsilon\approx 1{,}55\).
интервал накрывает значение 7,512 — выборочное среднее, посчитанное по исходным пятидесяти числам без группировки, — то есть результаты двух независимых расчётов не противоречат друг другу. Проверка порядка величины: \(\varepsilon\approx 2s/\sqrt{n}=2\cdot5{,}454/7{,}071 =1{,}543\), что практически совпадает с найденным 1,550, поскольку при \(n=50\) коэффициент Стьюдента 2,0096 уже почти неотличим от нормального квантиля 1,96. С последним получилось бы \(\varepsilon=1{,}512\) — интервал оказался бы у́же на 2,5 %, и это в точности плата за то, что генеральное СКВО неизвестно и заменено выборочной оценкой. Наконец, ширина интервала составляет около 40 % от \(s\): чтобы сократить её вдвое, объём выборки пришлось бы довести до 200 измерений.
Частые ошибки в этом типовом расчёте. Подставлять в доверительный интервал выборочную дисперсию вместо исправленной; забывать удвоить функцию Лапласа в симметричной задаче о нормальном распределении; применять формулу Пуассона там, где велико \(npq\) (и наоборот); при построении интервального ряда брать интервалы замкнутыми, из-за чего значения на границах учитываются дважды.
