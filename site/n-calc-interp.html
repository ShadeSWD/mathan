Интерполяция и приближение функций

По таблице из восьми точек строим интерполяционные многочлены Лагранжа и Ньютона, кубический сплайн и приближения методом наименьших квадратов. Таблицу можно править — все кривые, таблица конечных разностей и разбор «по шагам» пересчитываются сразу.

Теория к странице — глава 2 «Интерполяция и приближение функций»; аналитическая пара — «Ряды» (ряд Тейлора) и «Производная» (формула Тейлора).

Постановка задачи

Функция задана таблицей значений \((x_i, y_i)\), \(i = 0,\dots,n\). Требуется построить функцию, которая в узлах совпадает с таблицей (интерполяция) либо проходит «как можно ближе» к точкам (приближение). Через \(n+1\) узел с различными абсциссами проходит ровно один многочлен степени не выше \(n\) — способы его записи различаются лишь удобством вычислений.

Многочлен Лагранжа

Многочлен собирается из базисных множителей, каждый из которых равен единице в «своём» узле и нулю в остальных:

$$L_n(t)=\sum_{k=0}^{n} y_k\, l_k(t),\qquad l_k(t)=\prod_{\substack{i=0\\ i\ne k}}^{n} \dfrac{t-x_i}{x_k-x_i}.$$

Действительно, \(l_k(x_k)=1\) и \(l_k(x_i)=0\) при \(i\ne k\), поэтому \(L_n(x_i)=y_i\) для всех узлов. Погрешность интерполяции на отрезке оценивается через производную порядка \(n+1\):

$$f(t)-L_n(t)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(t-x_i).$$

Многочлен Ньютона

Для равноотстоящих узлов с шагом \(h = x_{i+1}-x_i\) удобна запись через конечные разности \(\Delta^k y_0\), которые строятся рекуррентно: \(\Delta y_i = y_{i+1}-y_i\), \(\Delta^k y_i = \Delta^{k-1}y_{i+1} - \Delta^{k-1}y_i\). Интерполяционный многочлен Ньютона «вперёд»:

$$N_n(t)=\sum_{k=0}^{n} \dfrac{\Delta^k y_0}{k!\,h^k} \prod_{i=0}^{k-1}(t-x_i).$$

Это тот же самый многочлен, что и у Лагранжа, — но добавление нового узла требует лишь одного нового слагаемого, а таблица разностей заодно показывает, до какой степени многочлена данные «информативны»: разности порядка выше полезного тонут в шуме.

Кубический сплайн

Вместо одного многочлена высокой степени — на каждом отрезке \([x_i,x_{i+1}]\) свой кубический многочлен \(S_i(t)\), склеенный с соседями по значению, первой и второй производной. Если обозначить \(M_i = S''(x_i)\), условия склейки дают трёхдиагональную систему

$$\dfrac{h_i}{6}M_{i-1}+\dfrac{h_i+h_{i+1}}{3}M_i+\dfrac{h_{i+1}}{6}M_{i+1} =\dfrac{y_{i+1}-y_i}{h_{i+1}}-\dfrac{y_i-y_{i-1}}{h_i},$$

где \(h_i = x_i - x_{i-1}\). Для естественного сплайна принимают \(M_0=M_n=0\); система решается методом прогонки, и на каждом отрезке

$$S_i(t)=M_i\dfrac{(x_{i+1}-t)^3}{6h_{i+1}}+M_{i+1}\dfrac{(t-x_i)^3}{6h_{i+1}} +\Bigl(y_i-\dfrac{M_i h_{i+1}^2}{6}\Bigr)\dfrac{x_{i+1}-t}{h_{i+1}} +\Bigl(y_{i+1}-\dfrac{M_{i+1} h_{i+1}^2}{6}\Bigr)\dfrac{t-x_i}{h_{i+1}}.$$

Метод наименьших квадратов

Когда точек много, а данные зашумлены, интерполировать все точки бессмысленно — ищут многочлен малой степени, минимизирующий сумму квадратов уклонений \(\Phi=\sum_i\bigl(P(x_i)-y_i\bigr)^2\). Приравнивая к нулю производные \(\partial\Phi/\partial a_j\), для прямой \(P_1(t)=a+bt\) получаем нормальную систему

$$\begin{cases} a\,(n{+}1)+b\sum x_i=\sum y_i,\\[2pt] a\sum x_i+b\sum x_i^2=\sum x_i y_i, \end{cases}$$

а для параболы \(P_2(t)=a+bt+ct^2\) — аналогичную систему третьего порядка с суммами до \(\sum x_i^4\). Если взять степень 7 по восьми точкам — такой «МНК» просто совпадает с интерполяционным многочленом: параметров столько же, сколько условий, и сумма квадратов уклонений равна нулю.
